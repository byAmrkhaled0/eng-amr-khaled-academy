# قواعد الكود في Techno Minds

نطاق هذه المراجعة: 67.8.5، مبنية على نسخة 67.8.4 المرفقة، 12 سبتمبر 2026. هذا الملف يحدد القواعد المطبقة في التغييرات الجديدة؛ لا يعني أن كل الملفات القديمة ملتزمة بها.

- الواجهة الحالية HTML وJavaScript بلا إطار؛ `assets/app.js` للبوابات و`assets/admin.js` للإدارة و`assets/firebase-sync.js` لتغليف اتصال Firebase. لا تنقل المشروع لإطار آخر لإصلاح عيب محدود.
- منطق الحساب والتحقق المشترك في `functions/lib`: النسخ `backup.js`، إجماليات الخزنة `payment-dashboard.js`، التقرير `monthly-report.js`، عنوان الطلب `request-ip.js`. `functions/entry.js` يصدّر وظائف `index.js` دون نسخة ثانية من الاستعادة.
- تحقق المدخلات والصلاحيات على الخادم. disabled في الواجهة لا يغني عن transaction أو جلسة صالحة. لا تستنتج عدم الدفع أو درجة صفر من بيانات لم تُحمّل أو لم تُصحح.
- استخدم async/await ومعالجة خطأ تظهر حالة قابلة للفهم. القراءة الفاشلة للتقرير لا تتحول إلى قائمة فارغة؛ فشل الدفع لا يتحول إلى نجاح. السجل المالي الملغى لا يقبل إعادة استخدام requestId.
- أسماء عربية في المنتج، أسماء نطاقية مستقرة في الكود. احتفظ بمفاتيح المستندات الأصلية في النسخ؛ لا تنظفها باستبدال صامت يدمج معرفين مختلفين.
- المصادقة، القراءة، الكتابة، وعرض النتيجة مراحل منفصلة. معاملات المال تؤكد من الخادم. الكتابة الأوفلاين تُسمى «محفوظ محليًا، ينتظر المزامنة».
- لكل عملية جديدة requestId مستقل؛ يُحتفظ به عند إعادة محاولة نفس البيانات فقط. قيد الطالب/الحصة مستقل عن requestId لمنع تكرار الحضور بين جهازين.
- التعديل في مصدر الميزة القائم؛ لا تضف ملف patch بإصدار آخر فوقه. الواجهات العامة القديمة على window بقيت للتوافق؛ الوحدات الجديدة في الخادم بلا اعتماد على DOM.
- لا تعدّل تعليمات الصلاحيات أو اختبارات الأمان للحصول على نجاح صوري. الاختبارات النصية تبقى فحص توصيل فقط؛ اختبر المعاملة والحالات والنتائج فعلًا.

## التحقق

`npm test` يجمع التحقق البنيوي، اختبارات الأعمال القديمة، واختبارات النطاق الجديدة. `npm run test:review:integration` يتطلب Java 21 ومحاكي Firestore وStorage، ويستخدم حصريًا `demo-technominds`. بيانات الاختبار مزروعة ومميزة، ولا يجوز توجيهها للإنتاج. `npm run build` ثم `npm run verify:dist` يتحققان من الحزمة العامة.

اختبارات الإصلاح: `scripts/review.domain.test.js` و`review.integration.test.js` و`review.service-worker.test.js`. معاينة المتصفح التجريبية: `scripts/browser/review.html`؛ مستبعدة من dist. نسخة الأداء السابقة تقارن عبر `scripts/review.performance.js BASELINE_ROOT before` داخل المحاكي فقط.

## استثناءات قائمة

ما زال index.js وapp.js وadmin.js كبيرًا، وتوجد ملفات ترقيعات CSS/JS متراكمة ومئات !important. لم يُنفذ تفكيك شامل، ولا تغطي اختبارات المتصفح كل الأزرار. خطة الاستعادة merge على دفعات، وليست transaction واحدة لكل قاعدة البيانات. التفاصيل وحدود الضمان في REVIEW_REPORT_AR.md.
