# خريطة الواجهة وحالاتها

| المسار | المستخدم والوظيفة | المصدر |
|---|---|---|
| index.html | الموقع العام، الحجز، التقييمات، ترتيب الطلاب | app.js، firebase-sync.js |
| materials.html | محاضرات عملي | setupUnifiedHeader، renderUnifiedResourcesPage |
| theory-lectures.html | محاضرات نظري، محاضرات المسار بالكود | app.js، curriculum-student.js |
| practical.html | محرر الأكواد وتشغيل اللغات | practical.js، خدمات Judge0 |
| student.html | بوابة الطالب والواجبات والنتائج والنقل | app.js، جلسة بوابة الطالب |
| parent.html | تقرير ولي الأمر بفترة مختارة | loadParentMonthlyReport، getParentMonthlyReport |
| exams.html | الامتحان والمحاولة المؤقتة والتسليم | app.js، startExam/submitExam |
| teacher-login.html | Firebase Auth ثم الأقسام الإدارية | admin.js والملفات الإدارية المؤجلة |
| about / learning-path / questions / reviews | التعريف والمسار والمحتوى والتقييمات | الصفحات الموجودة |

الهيدر المشترك يعرض محاضرات عملي → materials.html ومحاضرات نظري → theory-lectures.html. أُزيل إخفاء النظري في مقاسات سطح المكتب الوسطية. قائمة الهاتف تنسخ الروابط نفسها.

| المسار المعدل | تحميل/فارغ/خطأ | تأكيد/تعطيل/أوفلاين |
|---|---|---|
| الخزنة | تحميل معروف، خطأ مع إعادة محاولة، نتائج فارغة واضحة | لا تعرض غير المدفوع قبل اكتمال المصدر؛ زر العملية معطل أثناء الإرسال |
| الدفع الجزئي والسجل | طلب واحد لكل إجراء؛ سجل على صفحات | نجاح بعد إقرار active فقط، تعديل وإلغاء بصلاحية الإدارة |
| تقرير ولي الأمر | تقرير فترة محددة، تحذيرات نقص المواعيد والدرجات | تبديل الشهر يمنع وصول رد شهر سابق فوق المختار؛ آخر تحديث ظاهر |
| الحضور المحلي | رفض واضح إذا لم تجهز الحصة أو الكود | pending / syncing / synced / failed؛ يحتفظ بالإقرار والسجل |
| الاستعادة | معاينة عدد الكتابات والمجموعات المحفوظة والتعارض المالي | نسخة أمان قبل الكتابة، لا حذف تلقائي؛ تقدم تقني في _restore_runs، لا شريط تقدم مكتمل في الواجهة |

الهواتف: اختُبرت واجهة الخزنة والتقرير وقائمة الموقع في إطار متصفح بعروض 360 و390، والهيدر على 768 و1200. هذا محاكاة أبعاد، لا هاتف مادي. الصور في evidence. ثبت الوصول لآخر التقرير، وتمرير نموذج الدفع الطويل وحصر Tab داخله، وإغلاقه بـ Escape وعودة التركيز. حُدد قفل html/body للقائمة والحوار فقط ويُرفع عند الإغلاق؛ قوائم الهاتف فوق الهيدر وتخفي المساعد العائم أثناء الفتح.

RTL وlang=ar محفوظان. حقول الدفع المهمة لها أسماء وصول؛ مساحات حقول الهاتف 48px وفق CSS الحالي، وضوابط الحوار الجديدة 44px على الأقل. تبقى مراجعة لوحة المفاتيح المادية مع لوحة شاشة الهاتف، الوضع الأفقي والتكبير والطباعة PDF النهائية والامتحان الأخير/واجب طويل على أجهزة فعلية غير مكتملة.

لا ترسل واتساب أو تقييمًا أو حجزًا من وضع الاختبار. زر «الموقع والهيدر» يعاين الصفحة العامة وقد يقرأ بياناتها العامة؛ وضع الخزنة والتقرير في fixture يستخدم بيانات محلية مصطنعة ولا يكتب إلى Firebase.
