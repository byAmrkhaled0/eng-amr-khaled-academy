# الحركة والاستجابة

الهدف: استجابة مرئية في حدود 100ms دون انتظار الشبكة، ونتيجة مؤكدة فقط عند إقرار الخادم. لا يُقاس زمن التأكيد من انتهاء حركة الزر أو إغلاق الحوار.

- استُخدمت حالات تحميل وتعطيل الأزرار القائمة؛ الحضور الأوفلاين يعرض أنه محلي. المدفوعات والتقرير لا يعرضان نجاحًا وهميًا.
- القائمة المتحركة الموجودة في v56.css تستخدم transform وopacity بمدة تقارب 200–220ms. لا تنتظر انتهاء الحركة لتسجيل الضغط أو بدء الطلب.
- قواعد prefers-reduced-motion موجودة في v61-design.css وv67-learning-hub.css، وتقلل حركات البطاقات والأزرار والتمرير الناعم. الحفاظ عليها شرط لأي تعديل لاحق.
- مدة مقترحة للتغييرات الجديدة الصغيرة 120–200ms، ولإظهار الحوارات حتى 220ms. لم تُوحّد كل مدد الحركة القديمة أو كل keyframes.
- قفل التمرير محدود بالقائمة أو الحوار المفتوح؛ يُستعاد عند الإغلاق. لا تستخدم overflow:hidden لقص صفحة طويلة. مصدر القائمة والحوار عُدّل مباشرة، دون طبقة ترقيعات جديدة.

setupInteractionPerformance الموجود يسجل وقت إطار مرئي وتقدير انتهاء حالة الزر؛ هذه إشارة تشخيصية محلية وليست P95 لشبكة Firebase. القياسات المقبولة هنا موصوفة في PERFORMANCE_AND_COST.md، ولا تشمل فعليًا التشغيل البارد السحابي أو هاتفًا متوسطًا.
