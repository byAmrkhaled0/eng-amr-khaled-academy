# تطوير منصة Techno Minds — الإصدار 67.2.0

تاريخ التسليم: 8 سبتمبر 2026

## النتيجة

تم تنفيذ تحسينات عملية لتجربة الامتحانات والواجبات، خصوصًا على الهاتف، مع الحفاظ على بنية البيانات الحالية ومسارات الحفظ والتصحيح الآمنة في الخادم.

## الامتحان

- خريطة أسئلة قابلة للضغط توضّح السؤال الحالي والمجاب والمعلّم للمراجعة.
- إمكانية تخطي السؤال والرجوع إليه بدل إجبار الطالب على الإجابة بترتيب ثابت.
- زر مستقل لتعليم السؤال للمراجعة قبل التسليم.
- منع التسليم النهائي عند وجود إجابة ناقصة، مع الانتقال تلقائيًا إلى أول سؤال ناقص.
- مؤشر اتصال يوضّح العمل دون إنترنت، ثم يعيد محاولة مزامنة المسودة مع الخادم عند رجوع الاتصال.
- الحفاظ على العداد، واستكمال المحاولة، ومنع التسليم المكرر، وقفل الإجابات عند انتهاء الوقت.

## الواجبات

- عرض سؤال واحد في كل خطوة للواجبات متعددة الأسئلة لتقليل التمرير والتشتيت على الهاتف.
- شريط تقدم وعدّاد للأسئلة المجابة، مع أزرار السابق والتالي.
- الانتقال إلى أول سؤال ناقص عند محاولة التسليم قبل الإكمال.
- تثبيت منطقة التسليم أسفل شاشة الهاتف لتظل سهلة الوصول.
- الاحتفاظ بالمسودة المحلية لمدة 7 أيام فقط بدل 30 يومًا، مع تنظيف المسودات القديمة تلقائيًا.
- إضافة زر «مسح المسودة» وتنبيه واضح عند استخدام جهاز مشترك.
- تقليل البيانات المخزنة داخل المسودة، ومسحها فقط بعد تأكيد نجاح التسليم من الخادم.

## الجودة والتوافق

- لم تتغير عقود Cloud Functions أو صيغة بيانات تسليم الامتحان والواجب.
- تم رفع إصدار الواجهة وCloud Functions وكاش Service Worker إلى 67.2.0.
- تمت إضافة 6 اختبارات رجوع مخصصة للتطويرات الجديدة.

## التحقق

- `npm test`: نجحت 136 من 136 حالة.
- `npm run build`: ناجح.
- `npm run verify:dist`: ناجح لكل صفحات النشر الـ16.
- `npm --prefix functions run lint`: ناجح.
- `npm audit --omit=dev`: لا توجد ثغرات معروفة في حزم الواجهة أو Cloud Functions.

## النشر

لم يتم نشر الحزمة تلقائيًا على الموقع الحي. لتفعيلها، خذ نسخة احتياطية ثم انشر الواجهة وCloud Functions:

```bash
npm test
npm run build
firebase deploy --only firestore:rules,firestore:indexes,storage,functions,hosting
```
