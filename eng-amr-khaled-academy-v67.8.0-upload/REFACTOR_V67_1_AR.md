# ريفاكتور منصة Techno Minds — الإصدار 67.1.0

تاريخ التسليم: 8 سبتمبر 2026

## النتيجة

تم تنفيذ ريفاكتور محافظ على البيانات وعقود الخادم الحالية، مع التركيز على المشكلات التي تعطل أو تربك الاستخدام من الهاتف في التنقل والامتحانات والواجبات، ثم توحيد آلية الإصدار والكاش.

## ما تم إصلاحه

### الهاتف والتنقل

- إيقاف حذف شريطي التنقل السفلي للزائر ولوحة الإدارة من الصفحة.
- إعادة إظهار التنقل الأساسي على الهواتف والأجهزة اللوحية الصغيرة.
- إضافة مساحة سفلية آمنة للمحتوى ولوحة الإدارة.
- نقل زر المساعدة وزر الصعود فوق شريط التنقل حتى لا تتداخل مناطق الضغط.
- جعل شريط تبويبات الطالب قابلًا للتمرير مع مؤشر مرئي، وإضافة أدوار `tablist` و`tab` و`tabpanel` وحالة `aria-selected`.

### الامتحان على الهاتف

- استبدال ارتفاع `svh` بـ`dvh` مع بديل `vh` للمتصفحات القديمة، حتى تتكيف الشاشة مع ظهور لوحة المفاتيح.
- تعريف شاشة الامتحان كحوار modal وربط عنوانه دلاليًا.
- نقل التركيز تلقائيًا إلى حقل إجابة السؤال، وإعادته إلى زر بدء الامتحان عند الإغلاق.
- دعم زر Escape للحفظ والخروج بنفس مسار التأكيد الحالي.
- منع قارئ الشاشة من إعلان العداد كل ثانية، مع الإبقاء على حالة الحفظ كرسالة حية.

### الواجبات وبوابة الطالب

- توحيد منطق إعادة بناء بطاقة الطالب وربط أحداثها في `renderStudentPortal` بدل تكراره في عدة مسارات.
- إبقاء تبويب «الواجبات» مفتوحًا بعد التسليم الناجح.
- الحفاظ على التبويب الحالي عند التحديث التلقائي، وعلى تبويب النقل عند تحميل بيانات النقل.

### الإصدار والكاش والأداء

- رفع إصدار الواجهة وCloud Functions إلى 67.1.0.
- تعديل البناء ليضع إصدار الحزمة الحالي تلقائيًا على كل ملف CSS وJavaScript محلي في صفحات النشر.
- تعديل فحص `dist` لاكتشاف أي ملف بإصدار مفقود أو قديم.
- إزالة مكتبة QR من App Shell الأولي؛ ما زالت تُحمّل عند تشغيل الماسح فقط.
- إجبار تحديث الأصول في الخلفية على تجاوز كاش HTTP القديم.

### المراقبة

- أصبح `/api/health` يعتبر مزود Judge0 الافتراضي إعدادًا صالحًا بدل إظهار خدمة الأكواد متوقفة رغم نجاح التشغيل.
- نتيجة الفحص توضّح صراحة أن التحقق خاص بالإعدادات فقط ولا ينفّذ كودًا أو طلبًا مدفوعًا عند كل Health Check.

## التحقق

- `npm test`: نجحت 130 من 130 حالة.
- `npm run build`: ناجح.
- `npm run verify:dist`: ناجح لكل صفحات النشر الـ16.
- فحص JavaScript وJSON والروابط المحلية وسياسات الأمان الساكنة: ناجح.
- اختبار Firebase Emulator لم يُعد تشغيله في هذه البيئة لأن تنزيل ملفات المحاكي الخارجية غير متاح؛ لم يفشل أي اختبار قواعد تم تشغيله.

## النشر

لم يتم نشر هذه الحزمة تلقائيًا على الموقع الحي. لتفعيل التغييرات يجب نشر الواجهة وCloud Functions معًا بعد أخذ نسخة احتياطية:

```bash
npm test
npm run build
firebase deploy --only firestore:rules,firestore:indexes,storage,functions,hosting
```
